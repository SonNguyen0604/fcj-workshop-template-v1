### My overall experience

What I value most about FCAJ is the project-based learning approach instead of studying only theory. Building VPC, ALB, Auto Scaling, RDS, and CloudWatch helped me understand how AWS services interact and exposed trade-offs that are difficult to see from documentation alone.

### Satisfaction

I appreciate the opportunity to work with AWS, observe other teams presenting their projects, and listen to certification study/exam experiences. Activities such as Cloud Architect also made cloud knowledge practice more engaging.

### What could be improved

* Clarify the rubric and deliverables earlier so interns can better allocate time between the technical project, website, blogs, and event reports.
* When team structure changes, add a formal scope review so one person does not continue carrying a workload originally designed for multiple members.
* Add short practical sessions on troubleshooting, cost control, and collecting evidence/metrics for demos.

### Would I recommend the program to friends?

**Yes, if they are genuinely interested in Cloud/AWS and are comfortable with a high level of self-learning.** The program is suitable for learners who want hands-on practice and a demonstrable project, but it requires proactive documentation reading and time management.

### What I want to continue after the internship

I want to strengthen my AWS foundation, especially monitoring/observability, database resilience, and Infrastructure as Code operations. I also want to improve architecture presentation skills so I can explain service choices and solution limitations more clearly.

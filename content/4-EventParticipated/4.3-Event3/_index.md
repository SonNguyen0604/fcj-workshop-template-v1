# FCAJ Agentic AI Build Week - Project and AWS Experience Sharing

### Event information

* **Time:** 09:30 - 12:00, 25/07/2026.
* **Location:** Amazon Web Services Vietnam office, Bitexco Financial Tower, Ho Chi Minh City.
* **Role:** Attendee/observer.

### Main content

I participated as an audience member and observer. The session had two main groups of content.

**Project/product presentations:** teams took turns presenting products developed during the program. I observed how they introduced the problem, architecture diagram, AWS services, demo, results and implementation challenges. One of the presentations shown during the event was an **Adaptive AML Workflow Engine**.

**AWS learning and certification experience:** participants with exam experience shared how they built study plans, selected learning resources, practiced scenario-based questions and prepared for the actual exam environment.

### What I learned

* A cloud project is easier to understand when presented as **problem -> architecture -> implementation -> testing -> results**.
* Explaining **why a service was selected** is as important as listing the services used.
* A demo should include evidence and explicit limitations so the audience can distinguish completed work from future improvements.
* Certification preparation is more effective when learning through scenarios/use-cases and service trade-offs rather than memorizing definitions.

### Connection to my project

After this session, I refined my High Availability workshop to be easier to follow and validate: prerequisites, architecture, step-by-step deployment, testing/validation, limitations and clean-up. I also became more careful about separating **implemented**, **tested** and **future** items.
